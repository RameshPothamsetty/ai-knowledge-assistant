# Security policy

## Reporting a vulnerability

Email security@example.com with the details and a way to reproduce the issue.
Do not open a public issue for a suspected vulnerability.

## Supported versions

The latest minor release receives fixes. Older releases are supported for
thirty days after a newer minor release.

## Secrets

API keys are read from the environment and never committed. Rotate any key that
has been pasted into a ticket or a chat message.

## Access

Production access is granted per team through the platform group. Access is
reviewed every quarter, and accounts inactive for ninety days are removed.
